# list_generator
Crie listas de modo fácil com arquivos em pastas do seu computador.

COMO USAR:

1 - CARREGUE A PASTA COM OS ARQUIVOS QUE DESEJA LISTAR, ELES SERÃO LISTADOS AUTOMATICAMENTE,
2 - ESCOLHA O FORMATO QUE DESEJA EXPORTAR, PDF OU WORD, EXPORTE.

FUNÇÕES DO PROGRAMA:

1 - FUNÃO : ADICIONAR / EDITAR  OBSERVAÇÃO, SERVE PARA FAZER OBSERVAÇÕES EM ARQUIVOS QUE PRECISEM DE UMA OBSERVAÇÃO OU LEMBRETE.

2 - FUNÇÃO: AGRUPAR FILMES BASICAMENTE VOCÊ PODE CRIAR UMA ORDEM PERSONALIZADA PARA ALGUNS ARQUUIVOS, OS ARQUIVOS SE ORGANIZAM POR ORDEM ALFABÉTICA NATURALMENTE, VOCÊ PODE MUDAR A POSIÇÃO DE ALGUNS ITENS COM ESTA FUNÇÃO, APENAS FILTRE OS ITENS QUE DESEJA REORDENAR, DEFINA O ITEM ÂNCORA QUE VAI SERVIR DE REFERENCIA PAR OS OUTROS COM O BOTÃO DIREITO SOBRE O ITEM, E ORDENE ARRASTANDO E SOLTANDO DA MANEIRA QUE QUISER, SALVE.


OBS: QUANDO FIZER QUALQUER ALTERAÇÃO COMO AGRUPAR ITENS OU ADICIONAR OBSERVAÇÕES, SERÃO GERADOS ARQUIVOS XML, E .JSON NA PASTA DO SCRIPT, ELES ORGANIZAM AS ALTERAÇÕES E SALVAM PARA VOCÊ, NÃO APAGUE, SE APAGAR PERDE TUDO.
